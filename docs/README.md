# Documentación - Ferretería Inventario

## Estructura

### `fases/` — Implementación por fases del proyecto
Planes, resúmenes y validaciones de cada fase de desarrollo (Fase 1-4).

### `fixes/` — Correcciones y parches
Documentación de bugs corregidos y reclasificaciones aplicadas.

### `guias/` — Guías de uso y producción
Guías de instalación, empaquetado, ejecución de tests y uso del sistema.

### `reportes/` — Informes y resúmenes ejecutivos
Reportes de estado, resúmenes de tareas completadas e informes de producción.

### `sistema/` — Funcionalidades del sistema
Documentación de módulos y funcionalidades implementadas (precios, códigos, búsqueda, etc.).
